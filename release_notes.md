# VortexStrap v1.1.0 🚀

An alternative launcher for [Vortex](https://playvortex.io/) — a community-made Roblox-inspired game.

### What's New in v1.1.0:
- 📱 **Bloxstrap-style Launch Splash Screen**: Centered launch dialog featuring `Vortex_logo9.webp` logo, animated progress bar, status text, and logo credits for `music.mash`.
- 🍏 **macOS & Cross-Platform Support**: Added native macOS binary finding, Metal backend support, and OS compatibility guards.
- ⚡ **Instant Font Patcher Fix**: Sub-second dynamic font scanner with verified TTF table headers (`head`, `name`, `cmap`).
- 🕹️ **Fun & Retro Modes**: 240p Pixelated, 8-Bit Arcade, CRT Vintage, and Speedrunner graphics options.
- 📸 **In-Game Screenshot Gallery**: F12 screenshot hotkey and in-launcher preview gallery.

---

### How to Install (ZIP):
1. Download `VortexStrap-v1.1.0-Windows.zip` below.
2. Extract the contents into your Vortex folder (next to `Vortex.exe`).
3. Run `VortexStrap.exe`!
